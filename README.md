# gestor-de-notas-python
Programa en Python para introducir notas, calcular la media y comprobar si se ha aprobado, con validación de las calificaciones.

Gestor de notas en Python

Descripción

Este proyecto es un programa de consola desarrollado con Python que permite introducir las calificaciones de varias asignaturas, calcular la nota media y comprobar si se ha aprobado.

Incluye validación para controlar que las notas estén dentro del rango permitido.

Funcionalidades

* Introducir las notas de varias asignaturas.
* Calcular la media aritmética.
* Comprobar si la media es suficiente para aprobar.
* Validar las calificaciones introducidas.
* Mostrar los resultados por pantalla.

Tecnologías utilizadas

* Python 3

Cómo ejecutar el programa

1. Descarga o clona este repositorio.
2. Ejecuta el archivo Python desde una terminal o un editor compatible.
